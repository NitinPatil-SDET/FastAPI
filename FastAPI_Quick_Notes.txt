FASTAPI QUICK NOTES 🚀
=================================

📌 What is FastAPI?
---------------------------------
FastAPI is a modern Python framework used to build APIs quickly.

Benefits:
✅ Fast performance
✅ Automatic Swagger Docs
✅ Data validation
✅ Easy to learn
✅ Type hints support


🏗️ Basic Structure
---------------------------------

    Client
      |
      v
  FastAPI App
      |
      v
   Endpoint
      |
      v
   Response (JSON)


🚀 Create FastAPI App
---------------------------------
from fastapi import FastAPI

app = FastAPI()


🌐 First API
---------------------------------
@app.get("/")
def home():
    return {"message": "Hello World"}


📥 Path Parameters
---------------------------------
URL:

/users/101

Example:

from fastapi import Path

@app.get("/users/{user_id}")
def get_user(
    user_id: int = Path(..., ge=1, description="User ID")
):
    return {"user_id": user_id}


🎯 Why Use Path()?
---------------------------------

           Path()
              |
    -------------------
    |        |        |
Validation Docs   Constraints

✅ Validate input
✅ Add descriptions
✅ Min/Max rules
✅ Better Swagger docs


📤 Query Parameters
---------------------------------

/products?name=laptop

@app.get("/products")
def get_products(name: str):
    return {"name": name}


📦 Request Body
---------------------------------
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

@app.post("/users")
def create_user(user: User):
    return user


🔄 HTTP Methods
---------------------------------
GET     -> Read Data
POST    -> Create Data
PUT     -> Update Data
DELETE  -> Delete Data
